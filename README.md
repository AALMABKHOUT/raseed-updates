## طريقة التثبيت

1. افتح هالصفحة **من جوال الأندرويد** واضغط زر **حمّل التطبيق**.
2. لما يخلص التحميل افتح الملف واضغط **تثبيت**.
3. أول مرة بس: الجوال يسألك تسمح بالتثبيت من المتصفح — اضغط **السماح**.
4. افتح «رصيد» وسجّل دخولك برقمك والرمز السري.

## التحديثات

ما تحتاج ترجع هنا: لما تنزل نسخة جديدة، التطبيق نفسه يقفل ويطلب **حمّل التحديث**، تثبّته وتكمل — وبياناتك تظل مثل ما هي.

## هذا المستودع

فيه **ملف التطبيق ورقم آخر نسخة بس** (`version.json`) — ما فيه كود ولا بيانات مستأجرين ولا أرقام سرية.
